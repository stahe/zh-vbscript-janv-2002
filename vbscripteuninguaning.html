    2. VBSCRIPT的运行环境

    2.1. 简介

    vbscript程序并非直接在Windows系统下运行，而是运行在一个为其提供运行环境及若干专属对象的容器中。此外，该VBScript程序还可以使用Windows系统提供的对象，这些对象被称为ActiveX对象。

    在本文中，我们将使用两个容器：通常称为 WSH 的 Windows Scripting Host，以及下文有时称为 IE 的 Internet Explorer 浏览器。此外还有许多其他容器。 例如，MS-Office 应用程序就是 VB 的一个衍生容器，称为 VBA（Visual Basic for Applications）。 此外，还有许多 Windows 应用程序允许用户突破其限制，通过开发在应用程序内部运行并使用该应用程序特有对象的程序来实现。

    VBScript程序运行的容器起着至关重要的作用：

    • 容器向 VBScript 程序提供的对象因容器而异。例如，WSH 为 VBS 程序提供了一个名为 WScript 的对象，该对象可访问主机上的网络共享和打印机。 而 IE 则向 VBS 程序提供了一个名为 document 的对象，该对象代表正在查看的整个 HTML 文档。 VBS脚本程序随后即可对该文档进行操作。Excel 则向 VBA 程序提供了一系列对象，这些对象分别代表工作簿、工作表、图表等……实际上涵盖了 Excel 所处理的所有对象。
    • 虽然容器中的对象赋予了 VBScript 程序强大的功能，但有时也会限制其某些操作范围。例如，出于安全考虑，在 IE 浏览器中运行的 VBScript 程序无法访问主机磁盘。

    因此，在讨论 VBScript 编程时，必须明确程序在哪个容器中运行。

    在 Windows 系统中，VBScript 并非 WSH 或 IE 容器中唯一可用的语言。 例如，可以使用 JScript（=JavaScript）、PerlScript（=Perl）、Python 等。乍看之下，这些语言似乎都优于 VBScript。但 VBScript 却拥有显著优势：

    • VB及其变体VBSCRIPT和VBA在Windows系统中非常普遍。掌握这种语言似乎必不可少。
    • 程序的强大之处，更多在于其可用的对象，而非所使用的语言本身。而其中许多对象是由运行环境（容器）提供的，而非语言本身。

    VBSCRIPT的一个缺点是，它无法移植到Windows以外的系统上，例如Unix。而其竞争对手JavaScript、Perl、Python则具备这一特性。如果需要在异构系统上工作，在不同系统上使用相同的语言可能很有价值，甚至不可或缺。

    2.2. WSH 容器

    WSH（Windows Scripting Host）容器允许在Windows环境中执行用多种语言编写的程序，包括vbscript、javascript、perlscript、python等。若要在WSH中使用某种语言，必须符合相关标准。 任何符合该标准的语言均可作为在 WSH 中执行的候选语言。可以预见，此前列出的可在 WSH 中执行的语言列表可能会进一步扩展。 容器为所执行的程序提供了赋予其真正强大功能的对象。这往往会消除语言之间的差异，因为它们都使用同一组对象。因此，选择使用某种语言而非另一种，可能仅仅是个人偏好问题，而非性能问题。

    在 WSH 中，程序的执行依赖于两个可执行文件：wscript.exe 和 cscript.exe。 wscript.exe通常位于Windows安装目录中，该目录通常名为%windir%：

    
C:\ >echo %windir%
C:\WINDOWS

C:\>dir c:\windows\wscript.exe
WSCRIPT  EXE       123 280  19/09/01  11:54 wscript.exe

L'exécutable cscript.exe se trouve lui sous %windir%\command :

C:\>dir c:\windows\cscript.* /s

Répertoire de C:\WINDOWS\COMMAND
CSCRIPT  EXE       102 450  26/06/01  17:49 cscript.exe

    wscript 中的 w 表示 windows，而 cscript 中的 c 表示 console。 脚本既可以通过 wscript 也可以通过 cscript 执行。两者的区别在于屏幕上消息的显示方式：

    • wscript 会在一个窗口中显示
    • cscript 将其显示在屏幕上

    1. 容器 WSH 未与任何语言相关联。WSH 脚本可以在后缀为 .wsf 的文件中混合使用多种语言
    2. 此时脚本由 <job id="..."> ... </job> 标签包围

    4. 这种标记语言有一个名称：XML，即eXtended标记语言。XML并未定义任何标签，而是定义了标签的布局规则。 因此，这里应说明WSH脚本中使用的标记语言遵循XML标准。

    2.4. WSCRIPT 对象

    容器 WSH 为其执行的脚本提供了一个名为 wscript 的对象。一个对象具有属性和方法：

    一个 Obj 对象具有 Pi 属性，这些属性确定了它的状态。因此，一个 thermomètre 对象可能具有一个 température 属性。该属性是温度计状态的一个方面。 另一个属性可能是它所能承受的最高温度 Tmax。

    对象 Obj 可能具有方法 Mj，这些方法允许外部代理：

    • 获取其状态
    • 更改其状态

    因此，如果我们的温度计是电子的，它可能有一个方法 allumer 用于启动它，另一个 éteindre 用于关闭它，还有另一个 afficher 用于在达到平衡温度时显示该温度。 在编程术语中，方法是一种可以接受参数并返回结果的函数。

    在 VBScript 中，对象 Obj 的属性 Pi 表示为 Obj.Pi，方法 Mj 表示为 Obj.Mj。 WSH 中的 wscript 对象是一个重要的对象，因为它为脚本提供了多种方法。例如，其 echo 方法可用于显示一条消息。该方法的语法如下：

    wscript.echo arg1, arg2, ..., argn

    argi 参数的值随后将显示在窗口中（通过 wscript 执行）或屏幕上（通过 DOS 下的 cscript 执行）。
