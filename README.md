## 概述

VBScript 是一种适用于 Windows 的脚本语言，可用于多个领域。它易于学习，是通往 Windows 版 Visual Basic 的门户，因为它直接源自该语言。

尽管 VBScript 并非面向对象的语言（例如，不存在继承的概念），但它具备一些面向对象的特性。其强大之处在于能够利用运行环境提供的对象，以及 Windows 计算机上可用的 ActiveX 组件。这使其能够与最初功能更丰富的语言（如 Perl、JavaScript 或 Python）相抗衡。

## 运行环境

VBScript 可在多种环境中运行：

**Windows Scripting Host (WSH)**：用于在 Windows 中直接使用，特别是编写系统管理脚本。WSH 通常作为标准组件包含在 Windows 操作系统中。





**Internet Explorer**：用于 HTML 页面中，提供仅靠 HTML 无法实现的交互性。


**Internet Information Server (IIS) / Personal Web Server (PWS)**：通过微软的 ASP（Active Server Pages）技术，VBScript 用于服务器端的 Web 编程。





## 与 Visual Basic 和 VBA 的关联

由于 VBScript 源自 Visual Basic，因此它是了解这种在 Windows 生态系统中广泛使用的语言的绝佳入门途径。此外，它还能帮助用户为 **VBA（Visual Basic for Applications）** 做好准备，这是 Microsoft Office 套件（特别是 Excel）中使用的版本。

因此，VBScript 是开发 Windows 应用程序的理想切入点。
